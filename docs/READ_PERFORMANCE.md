# 读取成本与检查点复用验收

日期：2026-09-24（UTC+8）。灯溪镇 0.3.1；固定内核 0.13.2 / `7d3609853db34f3402754bd0860fee96115a9de1`。

## 改动边界

不改世界规则、数据表、MCP 参数或前端相机。每次 sync 仍读取并投影最新状态、重验身份和权限、取得最新事件流锚点。仅当可见内容完全相同、检查点距离过期超过 30 秒且不是传统 timeline 视图时，复用已有检查点，省去再次写入数据库。

返回 cursor 可以等于 base_cursor；observed_at 仍更新，事件仍使用独立的 stream_cursor。临近过期走原更新路径；已过期、被清理、跨身份或跨版本的游标仍要求重置。不使用全局隐藏状态变动决定游标轮换。

这不是把旧世界缓存几秒再给玩家看。时间驱动的投影仍执行，真实状态变化仍立即返回。传统 recipient timeline 保留原检查点更新路径。

测量脚本改用 contextlib.closing 明确释放只读 SQLite 连接，并新增回归用例。第一次诊断运行出现 1 次 ReadError 及连接未关闭导致的清理失败，不计为成功；修复脚本后重新取得完整配对结果。失败记录保留在隔离实验目录，未将失败算成通过。

## 同机短时对照

两名合成角色；每档目标运行 10 秒，轮询间隔 1.5 秒；初始化不计延迟。观察者结束前完成当前请求和等待，实际阶段约 11～13 秒。没有同时运行回归套件，零模型调用。

| 虚拟 HTTP 观察者 | 原版 P95 | 优化版 P95 | 成功请求：原 / 新 | 请求错误：原 / 新 |
|---|---:|---:|---:|---:|
| 10 | 50.3 ms | 34.3 ms | 67 / 67 | 0 / 0 |
| 50 | 2183.6 ms | 34.8 ms | 307 / 334 | 0 / 0 |
| 100 | 3299.9 ms | 2012.2 ms | 397 / 594 | 0 / 0 |

100 档仍约 2 秒 P95，不能标为百人流畅，不能等同于百个真实渲染浏览器。50 档跨过排队阈值的改善不代表所有负载都同比加速。

只有一组配对短时实验，无置信区间。CPU/RSS 因可选 psutil 未安装而未采集；没有测持续高频写入的活跃世界、公网延迟、云端账单和长期数据库增长。行数不增加不能单独证明零写入；专项测试直接检查 unchanged sync 未申请可写连接。

benchmark_observers 使用临时数据库与自动选择的本机端口，创建两个合成角色，完成后清理自己创建的进程和数据库。比较旧核时仅替换安装或隔离 PYTHONPATH 中的核心版本，保持世界、探针和机器不变。不接触真实玩家数据库。

## 剩余边界

两个真实模型互聊仍未执行：上一轮执行环境的拦截没有被绕过，受控 MCP/HTTP 测试不叫作真实模型自主合作。

当前收益是减少无变化观察的写放大。100 观察者剩余延迟、频繁变化的世界、真实模型宿主与公共部署仍需独立验证。本轮没有新增 Redis、Kafka、服务器 LLM、Sub-Agent、延迟世界缓存或供应商特殊重试。
