# Agent World 前端与运行契约复核记录

日期：2026-09-23。范围：本线程前端、MCP、数据、时态和低成本运行设计，不是全内核安全审计。

## 1. 结论

保留“Agent 语义决定 → 服务器事实裁决 → 客户端演绎”的架构。v0.3 是方向性收口，不足以证明前端和所有运行细节已完成。v0.4 将此前散落的细则统一，并区分当前代码、本版要求和真实测试结果。

此次为文档修改，不修补运行库、不升级内核、不改世界执行版本、不改生产数据库。旧 v0.2 的可选表演参数包不再作为首版实施要求。

## 4. 本轮实际执行

### 4.1 现有灯溪镇测试

在隔离目录将 `PYTHONPATH` 指向上述两个克隆，使用独立虚拟环境执行：

```sh
python -m unittest discover -s tests -q
```

实际输出：

```text
Ran 60 tests in 25.717s
OK
```

退出码为 0。日志有 asyncio 慢任务诊断；这不表示测试失败，也不应隐瞒有日志告警。未运行用户生产服务；测试创建的是临时测试状态。

### 4.2 气泡过期复现

针对未修改的内核 `agent_world/web/stream-client.js`，给同一角色推入两条 `at=100, expires_at=108` 的消息。先调用 `active(100)`，再调用 `active(110)`。

实际结果：

```json
{
  "first": ["first"],
  "late": [{"id":"second","expires_at":108,"started":110}],
  "expired_is_replayed": true
}
```

含义：第二句在绝对期限过去后才开始被当作现场气泡播放。现有测试通过并未覆盖该断言。

附件 `reproduce-bubble-expiry.mjs` 提供可移植回归探针。它在检测到该缺陷时以退出码 1 结束，这个失败是对缺陷的正确报告，不能改成测试成功。

```sh
node reproduce-bubble-expiry.mjs /absolute/path/to/agent-world
```

### 4.3 没有执行或没有证明的事情

没有跑完整浏览器视觉验收、两个真实外部模型宿主的自主往返、独立前端跨域接入、100 窗口压测、单调时钟跳变、所有 A01～A30 用例或生产安全审计。未运行这些项就不标通过。
