# 前端接通与示例素材验收

日期：2026-09-24（UTC+8）。版本：灯溪镇 0.4.0。
本线程范围：官方游戏前端、独立客户端接入、示例素材、客户端演绎与浏览器验收。
真实 Agent 自主游玩、模型宿主、内核规则和性能底座属于“查看架构分支线程”，不是本交付的前置条件。

## 1. 交付内容

- `sample-atlas.png`：可独立加载的透明 PNG 图集，不是截图占位。
- `sample-assets.json`：尺寸、版本、400 个帧矩形、脚底锚点、动作参数、来源和校验摘要。
- `sample-assets.zip`：图集、帧表、使用说明和仓库许可证。
- `/static/art-gallery.html`：桌面与手机可用的素材预览，支持动作和方向选择、暂停，不修改世界。
- 官方 Canvas 客户端：角色、地块、树、房屋、灯塔和物件实际使用图集；已有相机、点击和规则数据不变。
- 独立 SVG 查看器：自己读取公开 JSON/PNG，不导入官方绘图代码、内核 JS 或数据库。

## 2. 素材范围与结构

6 套外观：蓝衣、紫衣、玫瑰旅人，以及守灯人、匠人、花匠。
每套包含 4 个方向 × 待机/行走/说话/工作 × 每动作 4 帧，共 384 角色帧；另有 6 个地块、10 个场景物件，总计 400 帧。
PNG 为 1024 × 499 像素。本版图集约 89 KB；不需要模型、在线作画或逐帧网络下载。

帧结构为 `{x,y,w,h,anchor:[x,y]}`，坐标单位为像素；角色以脚底锚点对齐世界位置。每个世界格为 16 像素。贴图裁剪矩形不是碰撞箱，不参与世界规则。
图集源于本仓库原创程序化示例绘图，通过 `tools/build_sample_assets.py` 导出。不是外购素材，也不是商业游戏素材；使用范围见包内 LICENSE。2D 图集不是 3D 模型，不承诺自动生成骨骼或零适配任意世界。

## 3. 数据如何变成画面

优先级：服务器已接受的移动 > 已确认活动 > 当前有效发言的说话动作 > 待机。

| 数据来源 | 客户端表现 | 不做什么 |
|---|---|---|
| 权威 movement 路径与时间 | 四向行走帧、本地插值 | 不向服务器上传逐帧位置 |
| 权威 busy/repair 状态 | 工作帧与原有进度条 | 不以动画结束发奖励 |
| 有效、实际发布的 speech 气泡 | 发布者的中性说话帧与原文 | 不读思考，不替另一角色回答 |
| 无活动 | 待机、眨眼和环境效果 | 不制造新的移动、承诺或关系 |
| 服务器设施结果 | 切换灯塔明/暗素材 | 不靠客户端自行点亮世界 |

说话动作复用现有 BubbleQueue 的绝对过期判断；不另建一套对话计时器。公开打算不自动变成说话动作。历史补读不产生新气泡或说话循环。暂停素材预览、减少动态效果和关闭浏览器均不改变世界结果。

## 4. 加载与接通

官方与独立客户端都只需公开素材信息；不交出身份令牌。地图元数据增加可选的 `assets.manifest`，未改变内核、世界版本、MCP 参数、规则或计时器。
仅公开素材 JSON/PNG 增加和既有观察接口一致的指定来源 CORS。未扩大玩家控制、私有读取或身份 Cookie 权限。
素材清单有版本、大小、帧边界与必需角色帧检查；PNG 解码尺寸必须匹配。异常不标为载入成功。官方明确提示使用基础图形，独立客户端明确使用基础标记；世界数据仍可读，私有数据仍不返回。

## 5. 可重复的前端演绎场景

运行 `python tools/check_sample_assets.py`。脚本创建独立临时数据库、两个明确命名的测试身份和真实浏览器，通过现有 HTTP Action 驱动：

观察进入 → Alpha 行走 → Beta 靠近 → 双方各发一条真实消息 → 任务交互 → 收集 → 工作 → 服务器确认设施变化 → 刷新恢复。

同时检查独立 SVG 客户端的真实 PNG 加载、桌面和手机布局、减少动态效果、素材缺失后的显示与无凭据公开读取。页面不靠伪造状态完成演出。
输出位于 `test-results/sample-assets/`：逐阶段截图、`official-demo.webm` 和 `report.json`。这是一段受控测试演示，不冒充真实模型自主行为，也不替另一个线程验收内核。

## 6. 构建与边界

`python tools/build_sample_assets.py` 只生成静态资源；正式运行使用已生成的 PNG/JSON，不需要安装作画模型或 Playwright。图集通过现有 wheel 的 `web/*` 打包，需核对包内字节与源文件一致。
前端协议与相机继续沿用已验收版本；不为素材引入另一个游戏后端、渲染服务、消息平台或强制 Sub-Agent。这里只完成当前 2D 示例的前端与素材闭环，不声称所有新世界的玩法都无需适配。

## 7. 本地验收结果

80 项回归、相机数学专项、7 组真实浏览器脚本和 0.4.0 wheel 构建通过。新增脚本输出的 page_errors 为空。这里的“真实浏览器”不等于物理手机真机；手机视口、触控与减少动态效果使用浏览器仿真。

实测录像同时提供在 `/static/frontend-demo.html`，默认不预加载录像；仅主动观看时读取约 3.35 MB 视频，不增加正常游戏页面的下载量。素材 ZIP 约 67 KB，不含录像。

复核了桌面双角色对话、素材画廊和手机页面截图；图集实际接入游戏与独立 SVG 页面。运行状态与素材异常分开报告。UI、素材包和独立端的测试记录见 [证据 JSON](evidence/frontend-assets-2026-09-24.json)。远端 CI 与合并状态另行核实，不由本地通过推定。
