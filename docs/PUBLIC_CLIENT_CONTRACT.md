# Public reference frontend contract

Scope: Lantern Hollow presentation version 1, not all possible Agent World games. This document describes the ordinary HTTP adapter; a client does not need MCP or an identity token to observe public data.

1. GET /play/map: world_id must be lantern-hollow and presentation_version must be 1. Grid dimensions, tile names, buildings, targets and optional assets.manifest describe the public scene. Map geometry comes from the world; the renderer cannot move objects to change gameplay.
2. GET /watch/session: supplies view {kind:snapshot, view:spectator, viewer_role_id:null, world_version, view_version, cursor, observed_at, snapshot:{entities,resources,meta}}. meta.self is null. The outer object supplies events, server_time, stream_cursor, history_cursor, history, gap, has_older, has_more and history_truncated.
3. POST /watch/sync with {cursor:<view cursor>,stream_cursor:<event cursor>}, Content-Type application/json and X-Lantern-Client:1. A delta has base_cursor, cursor and delta {entities:{upsert,remove},resources:{upsert,remove},meta}. Apply only to the matching previous cursor and world/view versions. The resulting cursor MAY equal base_cursor when nothing changed. meta is a full replacement. A new snapshot replaces the entire view. Discard old in-flight responses after changing world or role focus.
4. Events have event_id, seq, occurred_at, kind, payload. Deduplicate event_id; order by seq within the village stream. Presentation payload has subject_id, name, channel, phase and data. User-authored speech is public_expression with channel speech; exact text is data.text. reply_to/message_id identify linked messages. Addressing somebody does not make the message private. Scripted dialogue and system feedback are not Agent thoughts.
5. A first load, result.history, result.gap or a history page is historical. Do not animate it as new speech. Start live speech only while data.expires_at is still in the future. The state snapshot and retained message stream are different things; neither reconstructs the other.
6. POST /watch/history with {history_cursor}, same headers. Returns events, history_cursor, has_older and history_truncated; these records are history. Keep at most 600 events in the reference client. This is not permanent storage.
7. Travelers have role_id, name, appearance, position:[x,y], facing, optional movement {path,start_at,end_at,step_seconds}, and optional busy {kind,start_at,end_at}. Interpolate the accepted path against server time; never upload animation coordinates. Clamping the animation at its endpoint does not itself confirm the action result.
8. Assets are optional. For this sample, /static/sample-assets.json declares schema lantern-sample-assets/1, atlas sample-atlas.png, frame bounds, anchors and version. Download with credentials omitted; a failed image uses a declared fallback, not a failed world. These are 2D example assets, not arbitrary 3D model support.
9. Keep exactly one sync in flight, stop unnecessary reads while hidden, use timeouts and bounded backoff. On invalid/expired cursor recover with a snapshot. On 401/403 clear any protected data; public observation never uses a player Cookie or Authorization header. A cross-origin deployment must be explicitly allowed by the world operator with --observer-origin. No wildcard private/control CORS is promised.

The independent implementation in examples/protocol-client uses only this contract and browser APIs, not app.js, render.js, the kernel SDK or direct DB reads. It proves an independent implementation path; it is not an external developer blind study because the same maintainer wrote and verified it.

Serve the directory with an ordinary static server, allow its exact origin on the world, enter the world origin and connect. Read model.js for snapshot/delta semantics. All world text is rendered as text, never executable HTML.
